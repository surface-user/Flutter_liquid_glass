# PR 审查清单

## 正确性

- [ ] 行为符合 `doc/task.md` 的验收标准。
- [ ] disabled、取消手势、组件销毁和快速重复交互不会留下错误状态。
- [ ] 修改覆盖所有调用方、导出、示例和文档。

## API

- [ ] 没有可由现有接口完成的重复组件或配置。
- [ ] 新公开 API 有文档、测试、README 示例和 CHANGELOG。
- [ ] 现有用户代码保持兼容；破坏性变更有版本计划。

## 性能

- [ ] 不逐帧改变模糊 sigma。
- [ ] 空闲时没有无意义 ticker。
- [ ] 高频动画不反复触发布局或整棵子树 build。
- [ ] BackdropFilter 范围有裁剪；重叠过滤没有错误共享 key。
- [ ] Android profile 数据与声明一致，不凭模拟器截图推断性能。

## 无障碍

- [ ] 系统和主题减少动画设置生效。
- [ ] 高对比度、减少透明度和关闭模糊后仍可读。
- [ ] 键盘焦点、语义、tooltip 和最小触控尺寸没有退化。
- [ ] 状态不只依靠颜色表达。

## 视觉与平台

- [ ] 浅色、深色、高对比度、fallback 均已检查。
- [ ] 圆形、圆角、直角表面没有裁剪或边缘漏光。
- [ ] 手机、桌面和放大文字没有溢出。
- [ ] Golden 差异是预期变化，不是简单覆盖基准。
- [ ] 不支持的 Shader / 平台路径有明确降级。

## 验证

- [ ] format、analyze、相关测试通过。
- [ ] Web release 构建通过。
- [ ] 发布相关变更通过 `flutter pub publish --dry-run`。
- [ ] PR 描述记录未验证的平台和剩余风险。

## 问题与修正

| 项目 | 原因 | 当前契约 |
| --- | --- | --- |
| 拖动重影 SINGLE-A | 原组件以20%透明度保留，选框与手柄仍显示，叠加全页浮动预览 | 移动中整体隐藏原组件、选框、手柄，仅保留一个全页预览；原组件保持挂载，取消/结束恢复，缩放时仍显示四边手柄 |
| 小背景与左上角 RUN-A | 背景绑定模块外框总范围，镜头无居中偏移，窗口变化不重新适配 | 背景铺满可用运行视口；按实际控件边界居中，保持相对位置；初始最多100%，窄屏缩小，窗口变化重新适应；可平移/缩放、适应画面、回原始大小 |
| 实际内容仍偏移 | 菜单/输入框预留外框大于真实控件，按外框居中不等于视觉居中 | 首次布局及窗口变化后读取真实根控件尺寸，重新适应一次；平时输入/点击不强制重置镜头 |
| 长中文导致镜头移动 | 事件文字换行挤压运行视口高度 | 事件栏单行省略，悬停查看完整文本，输入草稿与镜头保持 |

运行预览继续使用独立 Runtime 和导航器；重置恢复设计初值，退出不会回写设计。高对比使用可读纯色背景，减少动画规则保留；未新增持续动画或依赖。坐标仍为原1200×1200逻辑画布。原始大小可能超出窄屏，可平移或恢复适应画面。

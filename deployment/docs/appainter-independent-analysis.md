## 1. 方法、独立性与结论强度

首先通过 GitHub 连接器读取仓库与 main 分支元信息并固定上述 SHA，随后所有 Appainter 文件都按此 SHA 读取。源码内容只在研究工具会话内阅读，没有在本地保存、安装、运行或提交第三方源码。除本文外没有编写其他交付文件。报告最初写为 IN_PROGRESS，完成证据与表述复核后改为 REVIEW，供审阅。

## 4. 外壳、预览、设备模拟的隔离与边界

### 4.1 两套主题

外壳 `_MaterialApp` 使用固定 Colors.blue 种子生成 light/dark ThemeData，主题模式取 `HomeState.themeMode`；这个模式偏好通过 SharedPreferences 保存。顶栏太阳/月亮按钮改变的是外壳模式。[E04](https://github.com/zeshuaro/appainter/blob/c7e834b90dc47b68612d0a1db3a7b641438f3843/lib/app.dart#L218-L250)[E58](https://github.com/zeshuaro/appainter/blob/c7e834b90dc47b68612d0a1db3a7b641438f3843/lib/home/widgets/app_theme_mode_button.dart#L11-L24)[E60](https://github.com/zeshuaro/appainter/blob/c7e834b90dc47b68612d0a1db3a7b641438f3843/lib/home/cubit/home_cubit.dart#L59-L78)

### 8.1 Export 的实际交付物

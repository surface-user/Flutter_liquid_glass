# GlassLab · 组件实验台

独立 Flutter Web 应用。源码、组件库快照、测试、产物和 Sites 配置全部在本目录；不修改外层组件库。`packages/lightweight_liquid_glass` 是随实验台保存的快照，不会自动跟随外层库更新。

## 本地运行

需要 Flutter 3.44+、Dart 3.12+。

```powershell
cd app
flutter pub get
flutter run -d chrome
```

不能直接双击 `app/web/index.html`：它是需要 Flutter 构建替换占位符的源模板。正式网页必须由 HTTP 服务托管构建后的 `dist/`。

## 验证和构建

在本目录运行：

```powershell
cd app
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
cd ..
./build.ps1
```

构建脚本将网页放入 `dist/`，CanvasKit 随站点托管，另生成网页下载按钮使用的 `playground-source.zip`。旧网页产物保存在 `artifacts/dist-*`，不覆盖源码。下载源码解压后可按“本地运行”步骤启动；重建部署脚本仅在完整 Sites 工作目录提供。

布局保存在当前浏览器的 localStorage，重要布局请导出 JSON；切换浏览器或站点地址不会自动迁移布局。

## Sites 发布

复用 `.openai/hosting.json` 的现有项目 ID 和 `dist` 静态目录。按照 Sites 源码同步、打包、保存版本、发布流程更新，保持原访问权限。P0 的 GitHub 审查使用 `deployment/p0-review/repository` 隔离目录承载，各任务分别提交 PR；评审路径仍只在 deployment，不修改源组件库。

## P0 用途编辑（2026-11-14）

### 简洁导航与画布

左侧使用图标导航切换组件、图层、外观与属性。组件按操作、导航、容器、输入、内容、布局分组，支持折叠、搜索、点击和拖入画布；面板可收起，窄屏使用可关闭面板，大字体自动改为单列。

画布直接呈现组件，不再附带常驻名称标题条。选中时显示贴合控件的细轮廓与四边短手柄，普通编辑可直接拖动组件；点击空白取消选中。名称、复制和删除保留在图层/属性中；也可以将组件拖入左栏后才显示“松开即可删除”，此时释放，删除后使用顶部撤销恢复。旧布局数据不被清空。模块宽高全部用于内容可用区域；顶层按钮、图标按钮会填满此尺寸并居中内容，选框与真实按钮一致，运行预览尺寸和位置保持一致。新建按钮160×56、图标按钮56×56，尺寸下限48×48；内部表面仍不能超出该区域。

标签项、导航项、菜单、弹窗/页面入口、文字和图标按内容自动决定实际大小，选框贴合内容；普通模式只显示位置，不提供无效尺寸手柄或宽高输入，高级模式仍保留原始可用区域数据。按钮和容器的尺寸编辑保持原有规则。

从组件库拖出时展示真实组件的浮动预览；已有组件移动时也可跟随指针穿过画布、顶栏和属性区域；移动中原组件、选框与手柄一起隐藏，仅保留一份浮动组件，取消时原样恢复。轻微提起动效遵循系统/主题减少动画。预览可跨越全页，最终放置仍使用画布坐标和边界。只有已有组件进入左栏才出现删除区，移出立即收起；点击、选中、画布内移动及从库拖入都不显示删除提示。窄屏拖动时隐藏组件面板，保留活动手势，结束再关闭，取消不添加。

顶部“运行预览”左侧统一提供紧凑撤销/重做图标，窄屏同样保留；删除组件后不再弹出底部整条提示，使用顶部撤销恢复。

默认进入普通模式：按内容、操作、输入、容器与反馈、页面结构、布局选择14种用途；属性直接编辑常用内容、行为和外观。底层表面、分组、主题、路由及原始结构仅在高级模式提供，旧复杂内容完整保留。卡片新建默认静态。

弹窗按入口、说明/确认用途、标题正文、按钮与返回结果编辑，提供只读内容预览和真实试用。普通菜单、卡片等旧自定义弹窗明确转到高级编辑；普通按钮和独立弹窗提供专用编辑流程。普通画布只负责编辑，运行预览独立处理真实交互，支持重置和退出，不把运行草稿写回设计。预览背景铺满窗口，按实际控件边界居中并在窄屏自动缩小，保留相对位置；调整窗口后重新适应，提供实时比例、适应画面和原始大小。运行事件保持单行，长中文不会挤动画面。

整体外观提供标准、轻柔、快速动效方案，以及真实按压、材质、弹窗、页面试用；系统和主题的减少动画限制始终优先。任务与批次见外层 `deployment/docs/task.md`，本轮证据见 [VERIFICATION.md](VERIFICATION.md)。

## 参数与类型适配（2026-11-13）

数字和文字参数支持回车或失焦应用，错误不覆盖有效布局；模块外框与内部表面尺寸分别控制。组件类型按插槽筛选并重建对应参数，不支持项只读说明；可继承的值可以恢复默认。旧布局校验失败时保留原始数据并提供导出，保存前自动保留首份旧布局备份。完整契约、逐组件证据及验证边界见 [VERIFICATION.md](VERIFICATION.md)。

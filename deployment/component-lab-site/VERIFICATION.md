# 实验台参数与交互修复验收

日期：2026-11-13。依据：外层 `doc/component-lab-reference.md`，用户已审阅并批准实施。原手册第 1、8、10 节描述修复前基线；本文件记录批准后的契约与复验，不把旧诊断结论当成当前状态。

所有应用实现、测试、记录和产物位于 `deployment/`；外层组件库、示例和已有失败文件未修改。构建仍使用本目录已有组件库快照，未修改快照公开 API、依赖或渲染实现。

## 修复契约与手册问题对应

| 编号 | 当前行为与复验 |
| --- | --- |
| LAB-01 | 数字/文字回车或失焦提交；错误留在输入框中，旧有效布局不变；宽度修改以实际 RenderBox 尺寸断言，并验证撤销。 |
| LAB-02 | `模块宽度/高度` 控制含标题的画布外框；`内部表面宽度/高度` 控制表面本身。内部 120×90 与 360×220 已验证实际尺寸；放不下时拒绝并提示先扩外框。 |
| LAB-03 | 根/嵌套类型切换重建目标模板，仅迁移语义兼容字段；材质与文字样式分离；484 种根转换校验通过，真实下拉与撤销/重做另测。 |
| LAB-04 | 弹窗目标固定 GlassDialog，菜单项固定 MenuItemButton，图标固定 Icon；触发器/标题只允许非交互内容；普通内容与操作区使用各自白名单。固定类型禁用并显示中文说明。 |
| LAB-05 | 依据“组件 + 参数路径”定义类型；控件形状、材质形状、渐变种类、文字样式不再共用错误候选。渐变切换移除原种类专属方向字段。 |
| LAB-06 | 自绘按钮只展示真正消费的控件字段；当前条件不消费的字段只读说明。模板可继承的 padding/动画/间距等恢复继承；显式值可重置。 |
| LAB-07 | 所有声明的 schema 字段/枚举均有中文映射；配置 JSON 保留原始标识，兼容导入导出。 |
| LAB-08 | 深层编辑不无限缩进；下拉允许中文换行；已检查 22 组件的窄屏/桌面截图及 320 宽、200% 字体的目标弹窗选择器。 |
| LAB-09 | 外框 w=70–1100、h=65–1100，位置与尺寸均受 1200×1200 画布限制；内部尺寸/应用栏高度另有最小外框校验。最小外框仍可从属性面板复制/删除。拖拽历史上限统一为 60。 |
| LAB-10 | 控制器/焦点按稳定节点身份登记；重排保留对应草稿，类型替换/卸载释放不用的资源；菜单动作使用仍挂载的父上下文。已打开弹窗/页面是打开时的内容快照，修改目标后需关闭重开，界面已说明。 |
| LAB-11 | 在提交前校验插槽、枚举、数值/颜色、约束、渐变、动作和节点结构；错误不替换旧画布。旧未知字段保留但只读，不默认为生效；非法旧布局进入可导出恢复模式。 |
| LAB-12 | 说明导航/标签受控状态、标签关闭回调与移除模块的区别；绑定可驱动选中；缺少焦点/控制器或变量类型不合适时有中文事件说明，布尔绑定有默认回退。中文变量插值支持。 |
| LAB-13 | 画布合并系统高对比度，不能被主题 false 关闭；文字/图标与背景可读；低质量禁模糊、系统关闭动画、运行中减少动画及重叠背景分组隔离均有断言。 |

## 每个组件独立复验

每行均执行了该组件全部已声明顶层参数的有效样例校验与挂载，以及 5 宽度 × 3 字体大小布局检查；这与下列实际动作/视觉断言分别记录。有效样例挂载不代表穷尽该参数的所有取值和组合。

| 手册 | 组件 | 额外交互或效果证据 |
| --- | --- | --- |
| C01 | GlassCard | 点击事件、无动作静态状态、全局内边距继承与高对比文字。 |
| C02 | GlassButton | 鼠标/键盘触发、禁用、hover/pressed/focus/disabled 前景色；动作与外框分开。 |
| C03 | GlassIconButton | 点击/禁用、图标与动作适配；不再提供自绘按钮无效的原生固定/最大尺寸字段。 |
| C04 | GlassSurface | 内部尺寸、padding、alignment、材质实际值；外框不足时拒绝。 |
| C05 | AnimatedGlassSurface | 宽高与表面一致；样式/时长/曲线可继承，主题策略限制动画。 |
| C06 | GlassTextField | 中文文本注入、修改/提交、只读/禁用、focus/setText、缺失目标说明；重排草稿保持、资源释放。物理 IME 组合未验。 |
| C07 | GlassNavigationItem | 受控 selected 绑定与切换、点击事件、禁用；未绑定时不假装自动选中。 |
| C08 | GlassTab | 受控 selected、点击和独立关闭回调；关闭不误删模块。 |
| C09 | GlassToolbar | 操作区结构、间距/对齐参数与中文布局；组合操作沿子按钮动作链测试。 |
| C10 | GlassMenu | 真菜单、保留打开/禁用项、Esc、弹窗/页面动作与返回；没有失效上下文异常。 |
| C11 | GlassAppBar | toolbarHeight=72、bottomHeight=32 时实际高度104；bottom 为空时其高度不可编辑。 |
| C12 | GlassDialog | 嵌入预览与真弹窗区分，标题/正文/操作槽及约束可挂载；真实打开关闭另由 C13 与菜单验证。 |
| C13 | showGlassDialog | 正确目标正文、关闭、重复打开、允许/禁止遮罩关闭；目标类型只允许弹窗。 |
| C14 | GlassPageRoute | 正确目标页内容、系统返回及返回后父界面仍可操作；局部 motion 仅含实际支持项。 |
| C15 | GlassBackdrop | 配色/渐变/强度/动画样例；背景动画运行中遇到系统减少动画停止调度；高对比背景不透出任意低对比渐变。 |
| C16 | GlassGroup | 使用渲染后分组标识验证普通分组与 overlapping 隔离，防止共用背景过滤。 |
| C17 | LiquidGlassTheme | 局部合并/替换配置可挂载；全局继承、系统无障碍、低质量无模糊另有组合断言。 |
| C18 | Text | 内容、样式、行数等有效样例；行高明确为倍数；显式 normal/none 正确解析，中文变量插值。 |
| C19 | Icon | 合法图标候选、大小/颜色有效样例；可继承图标大小，高对比覆盖不可读前景。 |
| C20 | Column | 可用高度内 start→end 导致内容纵坐标实际变化；超高内容滚动；子节点重排保留草稿。 |

## 检查入口与证据

从 `app/` 依次运行：

```powershell
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub test --concurrency=1 --reporter expanded
```

随后在本目录运行 `./build.ps1`。稳定回归位于 `app/test/contracts_test.dart` 和 `app/test/lab_test.dart`；修复前 `artifacts/manual_audit_test.dart` 只作历史诊断，不是当前验收测试。

- 类型：22 种默认结构、484 种根转换、各插槽合法结构与非法候选拒绝。
- 中文：320/390/820/1180/1500 宽，100%/130%/200% 字体，合计330个组件视图；44张组件截图，加深层弹窗截图。已查看两组全组件拼图及关键原尺寸截图；测试截图不加载图标字体，正式网页另核对图标。
- 画布：40%/65%/85%/125%/150% 缩放下鼠标移动、大小调整、撤销重做；另有触摸拖动。
- 数据：JSON 回读不改节点身份、旧无效字段保留、非法类型/结构/尺寸/焦点重复拒绝；恢复模式不覆盖旧存储，首次写入前保留备份。浏览器存储配额不足等错误分支完成源码核对，未在真实配额耗尽环境注入验证。
- 日志：`artifacts/contracts-analyze.log`、`artifacts/contracts-full.log`；截图：`artifacts/contracts/`；保留原有失败与诊断产物。新增截图辅助逻辑曾因测试虚拟时钟等待文件操作而中止，已移入真实异步区间，原中止日志见 `artifacts/contracts-screenshot-io-before.log`。
